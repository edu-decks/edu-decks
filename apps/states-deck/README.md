# States Deck (`apps/states-deck`)

Interactive flashcards and multiple-choice quizzes for learning all 50 US states, capitals, geographic regions, and state outlines.

## Features
- **5 US Regions**: Northeast, Southeast, Midwest, Southwest, and West.
- **3 Card Types**:
  - `State → Capital`
  - `Capital → State`
  - `Map → State`
- **State Outline Toggle**: Show or hide the state shape clue on State & Capital cards.
- **Multiple-Choice Quiz**: 4, 6, or 8 options (defaulting to 8) with score and streak tracking.
- **Port**: `9006` (`pnpm --filter states-deck dev`)
